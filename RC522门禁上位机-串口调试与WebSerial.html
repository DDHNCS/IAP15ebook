RC522 门禁上位机

分两步调试：先用串口助手手敲命令验证协议，再用浏览器 Web Serial 打开 HTML 上位机。代码与下位机串口协议逐段解析。

第一步
串口助手调试协议
不写网页，先用 SSCOM / STC-ISP 自带串口助手把命令敲一遍，确认下位机协议通了。

1.1 准备工作

1

烧录程序

用 STC-ISP 把 RC522_key 工程的 hex 烧进单片机，烧完关闭 STC-ISP（串口被它占着，其他助手打不开）。

2

打开串口助手

推荐 SSCOM 或串口调试助手，选对应 COM 口，波特率 9600，8 数据位，无校验，1 停止位，勾选"发送新行"（每条命令末尾自动加回车换行）。

3

按复位键

MCU 复位后会主动输出 READY 和 VER=92，看到这两行说明串口通了。

1.2 逐条命令测试

在发送框输入预期返回说明
VERVER=92查询 RC522 版本
LSTTBL=0,EA5DDD06
TBL=END		列出卡表
ADD,2406BB06ACK=ADD,OK,1添加卡到槽位1
LSTTBL=0,EA5DDD06
TBL=1,2406BB06
TBL=END		确认加进去了
DEL,2406BB06ACK=DEL,OK,1删除槽位1
DEL,FFFFFFFFACK=DEL,FAIL,NOTFOUND删不存在的卡
CLRACK=CLR,OK清空卡表
XYZERR=BADCMD非法命令

1.3 刷卡事件（MCU 主动上报）

不用发命令，把卡往 RC522 上贴，串口会自动输出：

// 授权卡
EVT=OK,UID=EA5DDD06,IDX=0
LED=1000
// 5秒后
EVT=LOCK
LED=0000

// 未授权卡
EVT=DENY,UID=2406BB06
关键检查点：如果发命令没反应，先看有没有勾选"发送新行"——下位机靠 \n 分割命令，没换行它会一直等。其次确认波特率是 9600，不是 115200。
第二步
HTML 上位机逐段解析
用 Chrome / Edge 打开上位机网页，点"连接串口"，浏览器通过 Web Serial API 直接和单片机通信。

2.1 为什么用浏览器，不用 C# / Python

Web Serial API：Chrome / Edge 从 2022 年起支持浏览器直接读写串口。打开 HTML → 点连接 → 选 COM 口 → 就能收发数据。不用装任何软件，一个 html 文件双击就能跑，学生拷贝到自己电脑也能用。

2.2 整体结构

// 页面三大块：
header   // 连接按钮 + 状态灯 + 版本号
.grid
  ├─ .panel  // 门锁状态（4个锁图标，随 LED=xxxx 更新）
  └─ .panel  // 卡号管理表格 + 添加/删除按钮

2.3 连接串口（核心 5 行）

async function connect(){
  port = await navigator.serial.requestPort();   // 弹窗选 COM 口
  await port.open({baudRate:9600});             // 打开串口
  const td = new TextDecoderStream();
  port.readable.pipeTo(td.writable);                  // 收到的字节→字符串
  reader = td.readable.getReader();
  await readLoop();                              // 进入读循环
}

发送命令更简单：writer.write("ADD,EA5DDD06\n")。

2.4 按行解析（最关键的一段）

串口是字节流，没有"行"的概念。网页要自己按 \n 切行：

lineBuf += 收到的文本;
while((i = lineBuf.indexOf('\n')) >= 0){
  const line = lineBuf.slice(0, i).trim();
  lineBuf = lineBuf.slice(i+1);
  handleLine(line);       // 解析这一行
}

  const uid = input.value.trim().toUpperCase();

2.7 localStorage 本地记录

网页刷新后门锁状态和卡表不丢，因为每次更新都写进浏览器 localStorage：

localStorage.setItem('icdoor_host_v1',
  JSON.stringify({lockState, cards, version}));
常见坑：file:// 直接双击打开 html，Chrome 会因为安全策略拦截 Web Serial。解决：在 html 所在目录运行 python -m http.server 8000，然后浏览器访问 http://localhost:8000/RC522门禁上位机.html。或者直接用 Edge 打开，Edge 对 file:// 限制较松。

2.8 操作流程

1

连接串口

点"连接串口"→ 选 COM 口 → 看到绿灯"已连接"，MCU 版本显示 92。

2

看门锁状态

刷授权卡，网页上对应锁图标变绿，5 秒后自动变灰。

3

加卡 / 删卡

输入 8 位 UID → 添加；或在卡表点"删除"。日志区会显示 ACK=ADD,OK 等反馈。
